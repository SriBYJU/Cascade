# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in Cascade welcoming and respectful for everyone, regardless of background, identity, experience level, or perspective.

## Expected behavior

Be respectful, constructive, specific, and evidence-oriented. Assume good intent while reviewing ideas critically. Focus technical discussion on reproducible behavior, code, tests, benchmarks, security, and user impact.

Unacceptable behavior includes harassment, discrimination, personal attacks, threats, deliberate disruption, publication of private information, or other conduct that would reasonably make participation unsafe.

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions that violate this code. Serious or repeated violations may result in temporary or permanent exclusion from project spaces.

For conduct concerns that should not be public, contact the project maintainer through GitHub's private channels rather than opening an issue.

## Scope

This code applies in project spaces and when representing the project in public spaces.
